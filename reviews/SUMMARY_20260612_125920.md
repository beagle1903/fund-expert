# Parallel Code Review Summary
*Date: 2026-06-12 12:59:20*

This document synthesizes the findings from 5 specialized subagents (Architecture, Business Logic, Security, Test Coverage, and Performance) that performed a deep review of the `fundexpert` codebase.

## P0: Critical Issues
*No P0 (critical) issues were identified by any of the reviewers. The core business logic and pipeline dataflow are robust, mathematically sound, and secure.*

## P1: High Priority / High Impact Issues

### 1. Complex Parameter Passing in Pipeline (Architecture)
The core orchestrator function `run_pipeline` accepts 12 distinct arguments, causing bloat and tightly coupling `cli.py` to the function signature.
*   **Actionable Prompt:** "Refactor `fundexpert/pipeline.py` to introduce a `PipelineConfig` dataclass to encapsulate the 12 arguments of `run_pipeline`, and update `fundexpert/cli.py` to use it."

### 2. Redundant String Processing (Performance)
The same Turkish `i`/`ı` replacement logic and uppercasing are evaluated multiple times iteratively for every single row across the pipeline and selection logic.
*   **Actionable Prompt:** "Update `fundexpert/select/strategy.py` and `fundexpert/select/sector.py` to expect fully normalised and uppercased input strings, removing the internal `turkish_upper` invocation to avoid redundant string manipulation in `fundexpert/pipeline.py`."

### 3. Full DataFrame Deep Copy Overhead (Performance)
`score_candidates` begins by making a deep copy of the dataframe, which adds unnecessary memory and time overhead for pipelines managing a large number of rows and columns.
*   **Actionable Prompt:** "Refactor `score_candidates` in `fundexpert/scoring/score.py` to use `df.assign(score=...)` instead of `df.copy()` to avoid full dataframe deep copy overhead."

## P2: Enhancements / Considerations

### Architecture & Business Logic
*   **News Logic and Counterfactual Coupling:** `pipeline.py` handles too much low-level logic for the news penalty.
    *   **Actionable Prompt:** "Encapsulate the news integration and counterfactual evaluation in `fundexpert/pipeline.py` into a dedicated `NewsProcessor` class or `apply_news_stage` function."
*   **Implicit DataFrame Schemas:** Functions implicitly expect certain columns to exist without formal validation.
    *   **Actionable Prompt:** "Implement formal DataFrame schema validation after `merge_universe` using a library like `pandera` to enforce column presence and types."
*   **Horizon Scoring with Partial Data:** The `clean_candidates` function compares partial-period returns to full-period returns, which could slightly skew `R_hat` calculations.
    *   **Actionable Prompt:** "Update `fundexpert/scoring/horizon.py` to enforce stricter data completeness checks depending on the horizon bucket, penalizing or dropping funds lacking the full history for their target bucket."

### Test Coverage
*   **Cover Network Error Paths via Mocking:** The 5% uncovered code primarily involves edge cases in network failures and exceptions.
    *   **Actionable Prompt:** "Add a test case in `tests/test_news_penalty.py` that mocks `_query_for_prefix` to raise an Exception, asserting that the exception is caught gracefully and execution continues without failing the pipeline."
*   **Cover File System Error Paths in CLI:**
    *   **Actionable Prompt:** "Add test cases in `tests/test_cli.py` to mock `LAST_RUN_FILE.read_text` to throw an `OSError` and `json.JSONDecodeError`, ensuring `_load_last_run` returns an empty dict safely."

### Performance & Security
*   **Inefficient Column Dropping in Merges:**
    *   **Actionable Prompt:** "Refactor `fundexpert/data/merge.py` to slice needed columns instead of calling `drop()` before `merge()`."
*   **Type Inference Cost in CSV Parsing:**
    *   **Actionable Prompt:** "Supply a `dtype` mapping to `pd.read_csv` in `fundexpert/data/loader.py` for known non-numeric columns to speed up parsing."
*   **Suboptimal Row Iteration during Selection:**
    *   **Actionable Prompt:** "Switch to using a Python `zip()` over the specific underlying series arrays in `pick_top` (`fundexpert/select/pick.py`) instead of using `itertuples`."
*   **File Permissions on Windows for Temp Files:** Windows temp files could inherit broader permissions than intended.
    *   **Actionable Prompt:** "Update the cache file saving mechanisms in `fundexpert/history/store.py` and `fundexpert/cli.py` to explicitly apply restrictive Windows ACLs to the cache files."

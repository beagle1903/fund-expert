# Fundexpert Documentation

The live engineering contract is:

1. The repository `README.md` for setup, data, API, and operation.
2. `AGENTS.md` for implementation conventions and validation requirements.
3. The source and automated tests for exact behavior.
4. Generated API documentation under `docs/fundexpert/`.

The numbered Markdown documents and `implementation-plan.md` are historical
design records from before the CLI, Tavily news pass, strategy/sector caps,
FastAPI/React application, and validated bundle layer were completed. They are
retained for context and carry historical banners; do not treat them as current
requirements.

The more recent records under `docs/superpowers/` document specific news-pass
decisions and are also retained as implementation history.
